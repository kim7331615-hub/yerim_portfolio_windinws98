김예림 웹디자인 포트폴리오

실행
ZIP을 모두 압축 해제한 뒤 index.html을 Chrome에서 여세요.
이미지와 폰트가 들어 있는 assets 폴더를 같은 위치에 두세요.
실제 프로젝트 미리보기와 외부 링크는 인터넷 연결이 필요합니다.

구성
index.html    페이지 내용과 이미지·링크
style.css     레이아웃, 색상, 반응형 화면, 효과
script.js     돋보기, 슬라이드, 복사, 이미지 창, 기기별 미리보기
assets        피그마의 작업물 이미지와 로컬 폰트

반영된 동작
돋보기가 문구를 왼쪽에서 오른쪽으로 한 번 훑고 스크롤할 때 확대됩니다.
상단 메뉴가 고정되며 메뉴에 마우스를 올리면 글자 색이 바뀝니다.
스크롤하면 프로필 사진과 글이 올라옵니다. 스킬 그래프는 상단 메뉴 아래에 들어올 때 채워집니다.
PC·태블릿·모바일에서 팝업·포스터·히어로 배너가 차례로 상단 메뉴 아래에 고정됩니다.
마우스 휠을 내리면 각 구간의 첫 작품에서 페이지가 멈춥니다. 페이지가 멈춘 동안에는 작품만 가로로 움직입니다.
마지막 작품이 보인 뒤 더 내리면 다음 구간으로 내려갑니다.
가로 스와이프와 좌우 버튼으로 작업물을 넘길 수 있습니다. 세로 높이가 짧은 화면에서는 가로 슬라이드로 표시됩니다.
작업물을 클릭하면 이미지 창이 열립니다. 상세페이지는 전체 화면에서 읽을 수 있습니다.
상세페이지 창 상단에서 원본 PDF를 열 수 있습니다. 닫기 버튼은 스크롤해도 상단에 고정됩니다.
이미지 창은 닫기 버튼과 Esc 키로 닫을 수 있습니다.
이메일·전화번호 복사 및 복사 완료 안내
CONTACT의 이력서는 새 탭에서 PDF로 열립니다.
MELLOWEE·ONNONO·Windows 98 포트폴리오를 PC·태블릿·모바일 화면으로 미리 볼 수 있습니다.
기기 화면을 누르면 확대 창에서 실제 사이트를 조작할 수 있습니다. 창 안에서 화면 크기를 바꿀 수 있습니다.
개인프로필 웹페이지는 PROJECTS 아래 파란색 PROJECT 03에서 볼 수 있습니다.

화면 구성
1920px 목업을 기준으로 구성했습니다.
소개·WORKS 갤러리·프로젝트 설명 본문은 수정된 피그마의 24px 크기를 기준으로 화면 너비에 맞춰 표시합니다.
모바일에서는 프로필과 프로젝트 정보를 세로로 배치했습니다.
프로젝트 컬러와 서체는 피그마 자료 및 실제 사이트 스타일을 반영했습니다.
MELLOWEE 연결 주소는 피그마 주석의 GitHub Pages 주소를 사용했습니다.

이미지 해상도
패브릭·스킨케어·전기포트·캔들은 첨부된 PDF를 가로 1720px로 렌더링했습니다.
화면에서는 가로 최대 860px로 보여주고, 스크롤 위치에 가까운 이미지 조각부터 불러옵니다.
assets/detail에 상세페이지 원본 PDF와 화면용 WebP 이미지가 들어 있습니다.

폰트
Pretendard와 Playfair Display의 라이선스는 assets/fonts에 포함했습니다.
